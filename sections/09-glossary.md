# Glossary

| Term | Definition in VALI |
|------|---------------------|
| **VALI** | Deception-driven security fabric converting adversarial engagement into intelligence |
| **Progressive engagement** | Gating deeper decoy content on accumulated session actions |
| **Decoy** | Isolated fake surface that looks valuable |
| **Canary** | High-precision trap path or token |
| **Session** | Correlated interaction unit for one actor engagement |
| **Campaign** | Aggregate of sessions (reference: by source IP) |
| **Risk score** | Heuristic 0–100 priority signal |
| **Profile** | Coarse actor behavior class |
| **Kill-chain tag** | Stage-like semantic label on events/sessions |
| **Attack path** | Ordered sequence of kill-chain tags |
| **Playbook** | Automated defensive reaction hook inside VALI |
| **Blocklist** | Local list of high-risk sources for downstream use |
| **STIX-lite** | Simplified STIX-inspired export bundle |
| **Non-retaliation** | Principle forbidding offensive hack-back as core design |

## Name note

**VALI** deliberately echoes **Vāli / Vali** from the *Rāmāyaṇa* as a **metaphor** for asymmetric defensive advantage under engagement—not as religious instruction or supernatural claim.
